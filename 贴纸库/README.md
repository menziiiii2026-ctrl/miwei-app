# 贴纸库

这里存放可直接叠加的固定视觉资产，不在运行时重新生成。

## 分类

| 分类 | 用途 | 当前资产 |
|---|---|---|
| `boards` | 固定画板与画框 | 灰白周期画框（不内嵌周期文字） |
| `masks` | 固定形状的全局或局部暗层遮罩 | 灰蓝局部暗层遮罩 |
| `illustration-stickers` | 纯装饰性插画贴纸 | 白色手绘箭头组三枚 |
| `text-stickers` | 文字内容固定、仅承担氛围的贴纸 | 灰色字符胶囊、颜文字卡片 |
| `text-components` | 承载用户文案的可编辑文本样式 | 右下中文短句样式规范 |

## 模板目录

- `today-frame/`：灰白周期画框单食物模板；今日显示 `Today`，本周显示 `This Week`，标题是独立文本组件。
- `dark-outline-center/`：暗背景、主体居中、可调手绘描边、雏菊与蜜蜂模板。
- `local-gray-board-lower-subject/`：真实背景、局部暗层遮罩、偏下主体、白色描边与上方线稿模板。
- `two-item-diary-collage/`：2_模板1；固定半透明记事本贴纸、双产品对角构图、粉笔圆描边、星星与记录文案模板。
- `two-item-open-notebook/`：2_模板2；固定牛皮纸上下页线圈本、右上—左下双产品照片、夹子与横向食物插画模板。
- `three-item-rect-stack/`：3_模板1；三张等宽矩形裁切窗口、圆盘居中裁切与三段编辑式文案模板。
- `three-item-timestamp-stack/`：3_模板2；时间戳、三张矩形裁切窗口、两侧点阵星星与底部短句模板。
- `three-item-mask-triangle/`：3_模板3；局部黑色透明遮罩内的三角排盘、可删白描边与粉笔插画模板。
- `four-item-s-curve/`：4_模板1；四盘左侧 S 形路径、可换强调色描边、粗虚线连接器与可爱食物插画。
- `four-item-bracket-grid/`：4_模板2；四盘 2×2 中部裁切、同心圆弧括号、编号与黄色星星贴纸。
- `five-item-staggered-columns/`：5_模板1；五盘左三右二的折角双列、独立文字轴与直线连接贴纸。
- `five-item-bracket-slices/`：5_模板2；五盘交替中段裁切、细白括号与数据绑定的粗体中文菜品名。
- `six-item-polaroid-ring/`：6_模板1；两种固定拍立得画框、盘内氛围色底与半透明圆形胶带贴纸。
- `six-item-growing-polaroid-trail/`：6_模板2；可支持 5–7 菜的递增拍立得轨迹、柔光四角星芒与季节日期文字组件。

## 使用原则

- `boards`、`masks` 与 `illustration-stickers` 必须从资产库选用，不能让 AI 临时生成。
- `text-stickers` 可随机选用、替换或省略，但不能改成高饱和色。
- `text-components` 不作为固定文字贴纸；保留其字体、颜色、位置范围和避让规则，内容由用户提供。
- 每个模板建立独立子目录，资产文件名使用稳定编号，便于后续随机抽取和复刻。
- 无论 Figma 测试容器大小如何，所有模板最终只导出竖版 3:4 工作画板；完整规则见 `../模板拆解/00-全局出图规范.md`。
