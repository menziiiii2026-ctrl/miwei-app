# 参考图材质与色卡

## 材质判断

- 图 3 右侧：白色棉麻或亚麻混纺平纹布。经纬纱清楚、表面偏哑光，有轻微粗细不匀的竹节纱，不是丝绸。
- 图 5 盘子下方：同类白色棉麻桌布，织孔比图 3 更规整，视觉上接近中细号 canvas / cotton-linen tablecloth，不是针织物，也不是粗麻袋布。
- 图 3 的 Logo 和图 8 的图形：核心不是特殊字体，而是把棕粉色织物照片裁进文字或图形内部。实现关键词是 `texture fill`、`background-clip: text` 或设计软件中的剪切蒙版。
- 图 6、7：白色缎面、丝棉或高支数棉缎经过大幅虚化和提亮。关键特征是宽而浅的褶皱、珍珠白高光、冷灰阴影和很低的局部对比；若改成清晰真丝，会显得过于婚纱或奢侈品。

## App 使用建议

1. 主页面优先使用 `app-bg-pearl-silk-cotton.png`，再叠加 15%–25% 的暖白蒙版，保证列表和正文长期可读。
2. 食物详情页、商品卡背景可用 `app-bg-ivory-cotton-linen.png`；纹理不要再额外锐化。
3. Logo 或 36px 以上的大标题可用 `logo-texture-dusty-mauve-linen.png` 做剪切蒙版；小字号正文仍用纯色 `#A88898`，否则会发虚。
4. 丝绸底图上的正文建议用更深一档的灰粉，例如 `#80626C`；`#A88898` 更适合大标题和辅助信息。
5. 生成图为 App 竖屏比例 853×1844，可直接全屏 cover。开发接入示例见 `tokens.css`。

## 生成提示词摘要

- 丝棉：珍珠白丝棉混纺、宽浅褶皱、中心留白、漫射窗光、低对比、无物件与文字。
- 棉麻：象牙白棉麻平纹、清楚经纬纱、少量竹节纱、哑光、俯拍、无褶皱与物件。
- Logo 纹理：低对比灰粉棉麻、自然染色、平纹纱线、平整拍摄、适合裁进大字。

## 餐盘阴影规则（参考图 5）

- 主光从盘子的 10–11 点钟方向进入，阴影落向右下方约 4:30–5 点钟。
- 阴影由两层组成：贴近盘沿的小范围接触阴影，以及更宽、更淡的环境阴影。
- 偏移按盘子直径计算：水平向右 `2%–3%`，垂直向下 `4%–5%`。
- 模糊半径使用盘子直径的 `6%–9%`；总透明度控制在 `10%–16%`。
- 中性灰推荐 `rgba(88, 90, 98, 0.13)`；灰紫版本推荐 `rgba(118, 102, 125, 0.15)`。不要使用纯黑。
- 300px 盘子推荐双层参数：`2px 5px 7px rgba(70,72,80,.10)` 与 `8px 14px 24px rgba(88,90,98,.13)`。
- 若一张透明 PNG 同时包含盘子和食物，应在盘子后方单独绘制 92% 大小的模糊椭圆，避免整张图片的食物轮廓也产生阴影。

## App 背景纹理尺度与观察距离规则

- 纹理应在手机正常观看距离首先呈现为综合色和材质气氛，靠近观察时才看见单根纱线或提花结构。
- 这里调整的是观察距离，而不是编织密度：保留同一块布原有的花纹、纱线关系和材质结构，让镜头后退约 4 倍、扩大可见布面范围，再适配回相同尺寸的画布。
- 最终效果是原有花纹单元在画面中的宽高约缩至 25%，看起来像从更远处拍摄；不得重新设计花纹，也不得只增加纱线或花纹数量。
- 扩展布面时应自然续接原材质，不能简单做 4×4 平铺或镜像拼接，避免重复块、接缝和摩尔纹。
- 背景大纹理单元建议不超过屏幕短边的 3%–6%；Logo 内部的纱线单元应更小，避免文字呈现颗粒点阵。
- 开发中背景图使用 `cover` 即可，不要再通过 `background-size` 放大纹理；Logo 纹理也不应放大超过图片原生像素比例。
