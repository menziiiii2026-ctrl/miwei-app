# 3_模板3｜三菜暗层三角拼贴模板

> 文本的精确坐标、文本框、字号、字体、颜色、层级、最大行数、溢出策略、对齐与运行时绑定见 [文本排版坐标规范](文本排版坐标规范.md#3-道菜)。App 从本模板 manifest 的 `text_layout_ref` 读取，不得根据参考图重新估算。

## 模板定位

沿用 `1_模板3` 的核心层级：真实背景之上有一个独立的局部黑色半透明遮罩，三张透明餐品图与插画都在遮罩上方。三张餐品构成不规则三角，不得越出遮罩边界。

## 背景与暗层遮罩

- 正式画布为 `3:4`；背景从真实背景库选择，不使用吸色纯色替代。
- 遮罩类型为 `mask / local-dark / black`，默认 `#000000`、透明度 `20%`，位于背景上方、全部主体下方。
- 遮罩约为 `80%W × 85%H`，水平居中，上下留白相近；边缘直角即可，不做蓝灰色。

## 三道菜三角构图

| 主体 | 中心锚点 | 宽度 | 视觉职责 |
|---|---:|---:|---|
| A | `(67%W, 31%H)` | `30%W 至 34%W` | 右上，小而亮。 |
| B | `(36%W, 53%H)` | `40%W 至 46%W` | 左中，最大主体。 |
| C | `(59%W, 73%H)` | `40%W 至 44%W` | 下方横向主菜，压住底部视觉重量，且完整留在遮罩内。 |

- 三张均为独立透明实物图；主体外可放独立粗糙白描边，描边与餐盘留缝，不能遮住食物。
- 任何主体、描边或贴纸都不能超出局部暗层遮罩。

## 插画与文字

- 空白处放 `2 至 5` 枚白色粉笔插画：饮品、点赞手势、小星星等；全部来自固定贴纸库。
- 可放一段白色手写／打字机英文微文案，位于右中空白区；不复刻参考图的长句。
- 不把插画当成遮挡物；它们只补足三角外的空白。

## 图层顺序

1. 真实背景图。
2. 独立局部黑色透明遮罩。
3. A/B/C 的独立白色粗糙描边。
4. A/B/C 的透明餐品图。
5. 粉笔插画与微文案。

## 验收

- 遮罩是独立黑色透明层，位置与上下左右边距均衡。
- 三个主体在遮罩范围内形成右上—左中—下方的不规则三角。
- 描边可独立删除，插画可独立替换；最终输出严格 3:4。
