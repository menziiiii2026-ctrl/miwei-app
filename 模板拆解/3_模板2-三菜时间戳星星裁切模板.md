# 3_模板2｜三菜时间戳星星裁切模板

> 文本的精确坐标、文本框、字号、字体、颜色、层级、最大行数、溢出策略、对齐与运行时绑定见 [文本排版坐标规范](文本排版坐标规范.md#3-道菜)。App 从本模板 manifest 的 `text_layout_ref` 读取，不得根据参考图重新估算。

## 模板定位

与 `3_模板1` 共用“圆盘截图窗口”逻辑，但改为更规整的三张纵向卡片、顶部时间戳、底部居中短句与两侧点阵星星。背景可以是同一张真实图，也可按上下区域拼接两张色调一致的真实背景；重点在中间三张卡片的大小、位置和星星留白。

## 圆盘截图窗口

- 每张窗口为横向 `3:2`，窗口内圆盘中心对齐，圆盘直径等于窗口宽度。
- 透明圆盘的四个角由独立的、与背景综合色温协调的底色层承托。
- 这是窗口裁切效果，不是把透明圆盘转换成方形素材。

## 比例与位置

| 元素 | 位置／尺寸 |
|---|---|
| 时间戳 | 画布顶部约 `11%H`，水平居中，小字号。 |
| 三张窗口 | 均为 `52%W × 35%W`；中心约在 `(50%W, 29%H)`、`(50%W, 51%H)`、`(50%W, 73%H)`。 |
| 底部短句 | 画布约 `90%H`，水平居中。 |
| 点阵星星 | 两侧空白区随机 `6 至 10` 枚，三档尺寸，不能排成规则边框。 |

## 文案与贴纸

- 时间戳是固定文字贴纸，默认 `14:30 pm`，可替换为真实时间。
- 底部短句默认 `# tasty afternoon on #`，可从固定词库替换。
- 点阵星星为独立 `illustration-sticker / symbol / dotted-star`，从贴纸库调用，不实时生成。

## 图层顺序

1. 真实背景图（或色调一致的上下背景区）。
2. 三个窗口角落底色。
3. 三个受窗口裁切的透明圆盘。
4. 两侧点阵星星。
5. 顶部时间戳与底部短句。

## 验收

- 三张窗口比例一致，居中纵向排列；圆盘裁切规则同 `3_模板1`。
- 时间戳与底部文案均为居中对齐。
- 星星只填充两侧留白，不遮挡窗口与文字。
