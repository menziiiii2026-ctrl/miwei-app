# 固定装饰层协议与 14 模板审计

本协议只记录由模板编译器确定的非文字视觉结构。文字的坐标、字号与绑定仍唯一由 `app-contract/template-text-layouts.v1.json` 管理；背景照片和餐盘位图也不属于固定装饰。

每个 manifest 的 `reference_canvas_px` 是其 Figma 验证画板坐标系，`fixed_decoration_layers.coordinate_unit` 固定为 `px`。每个固定层均包含 `id`、`type`、`purpose`、`asset_ref` 或 `drawable`、`frame_px`、`rotation_deg`、`opacity`、`z_index`、编辑/删除开关、颜色绑定与 fallback，以及确定的 `appearance`。`figma_node_id` 是本次审计的原始节点证据。

`subject_clip_window` 是主体的固定裁切几何，不是餐盘本体；其 `deletable` 必须为 `false`。所有 `appearance.default_visible` 为 `true` 且条件为 `always`，模型不得决定是否出现，也不得输出坐标。`intent.mood.accent_color` 只替换明确声明该绑定的层；其余层使用 `fallback_color`。

App 按 `layer_stack` 升序渲染：背景 → 前置画板／遮罩／轮廓／裁切层 → 餐盘 → 路径与前景装饰 → 文字 → 顶层贴纸。图层中已含 Figma 实际顺序，不能用模板说明或参考图重新推算。
