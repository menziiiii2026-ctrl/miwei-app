# 1_模板3｜局部暗层遮罩偏下主体单食物模板

> 文本的精确坐标、文本框、字号、字体、颜色、层级、最大行数、溢出策略、对齐与运行时绑定见 [文本排版坐标规范](文本排版坐标规范.md#1-道菜)。App 从本模板 manifest 的 `text_layout_ref` 读取，不得根据参考图重新估算。

## 模板定位

用于主体不在画布正中心、而是明显偏下的单餐品照片。通过主体上方的线稿插画补足视觉重量；背景素材与主体之间叠加局部黑色半透明暗层遮罩，形成“真实背景、暗层遮罩、实物”三个层次。主体使用可调白色描边，周围加入少量装饰文字。

本模板与 Today 画框模板、全背景暗层遮罩居中模板完全独立，不共享遮罩和贴纸坐标。

## 画布与主体比例

参考画布固定为竖版 3:4。三个模板必须使用完全相同的有效画布比例和尺寸，禁止只改单个模板而造成并排预览高矮不一致。验证容器比 3:4 更高时，只在容器中建立一个明确的 3:4 工作区，剩余空间不属于成图。所有参数使用相对坐标。

- 单圆盘中心约为 `(50%W, 67%H)`，水平严格居中、垂直明显偏下。
- 托盘、饮品等多个物件组成的主体组宽约 `68%W 至 75%W`；只有单个圆盘时，圆盘宽约 `42%W 至 48%W`，默认 `45%W`。
- 主体上方保留约 `30%H` 的区域，由局部暗层遮罩与白色线稿插画承担视觉重量。
- 主体下方不设置正式文本框；装饰文字可以沿主体两侧斜向分布。

## 层级结构

从下到上固定为：

1. **原始图片背景**：树林、街景、室内或任意真实场景。
2. **局部暗层遮罩**：位于画面中部，压暗部分背景但不覆盖整个画布。
3. **可调白色描边层**：根据主体遮罩生成，位于局部暗层遮罩上方，并与主体边缘保留空隙；不属于贴纸。
4. **主体实物层**：单个餐品，或被视为一个整体的托盘餐品组。
5. **插画贴纸层**：上方风线涂鸦与小爱心。
6. **装饰文字贴纸层**：`bakery` 与 `foodie mood` 一类固定氛围文字。

## 局部暗层遮罩

这是本模板区别于上一招的核心元素。上一招使用覆盖全部背景的暗层遮罩；本模板只在中部叠加局部暗层遮罩，让原图背景仍从遮罩四周显露出来。

- 类型：固定形状的局部蒙层遮罩，不在运行时生成形状；运行时只允许调整颜色和透明度。
- 水平方向严格居中：`left = right`；默认左右边距各 `14.5%W`，遮罩宽约 `71%W`。
- 垂直方向严格居中：`top = bottom`；默认上下边距各 `6.3%H`，遮罩高约 `87.4%H`。
- 默认颜色：黑色 `#000000`。
- 默认透明度：`20%`，可调范围 `15% 至 30%`。
- 默认形状：竖向矩形遮罩。核心约束是上下边距相等、左右边距相等，不使用偏心位置。
- 暗层遮罩位于背景上方、所有主体、描边、插画和文字下方；主体不能随遮罩一起降低对比度。
- 暗层遮罩的作用是把复杂背景变成相对安静的视觉区域，而不是彻底遮住背景。

## 主体位置与视觉平衡

- 使用主体完整外接框定位，单圆盘默认中心为 `(50%W, 67%H)`。
- 允许水平中心在 `46%W 至 54%W` 之间调整。
- 允许垂直中心在 `64%H 至 70%H` 之间调整，但不得回到完全居中。
- 多物件主体组宽度建议为 `68%W 至 75%W`；单圆盘宽度建议为 `42%W 至 48%W`。
- 主体偏下后，上方必须出现至少一个中型线稿插画；否则画面会头轻脚重。
- 上方插画组的视觉中心放在 `(38%W, 28%H)` 左右，与偏下主体形成对角平衡。

## 可调描边效果

本模板面对的是俯拍圆盘，描边直接由代码生成独立正圆，不制作成贴纸，也不从食物轮廓推导。

- 默认颜色：奶油白 `#FFFDF3`。
- 默认宽度：画布宽度的 `0.8%`。
- 可调范围：`0.5%W 至 1.2%W`。
- 默认形状：与圆盘同心的正圆。
- 描边圆直径 = 圆盘直径 + `2 × 留缝`；默认单侧留缝约 `2.7%W`，可调范围 `2%W 至 4%W`。
- 描边必须完整位于盘沿外侧，不能盖住圆盘或食物。
- 颜色和粗细可按背景对比度修改；深背景优先白色，浅背景可改深灰或品牌色。

建议算法：读取圆盘外接正方形，以同一中心点创建直径增大 `2 × gap` 的圆形矢量；填充为空，只设置描边颜色和粗细。

## 贴纸分类

### 风线涂鸦

- 类型：`illustration-sticker / line-doodle / wind-motion`。
- 白色细线，包含两条卷曲线和三条平行速度线。
- 位于主体上方偏左，参考锚点 `(38%W, 28%H)`。
- 宽约 `25%W 至 29%W`，高约 `11%H 至 14%H`。
- 它是主要平衡贴纸，必须出现。
- 不允许复制多次；只使用一个完整风线贴纸组。

### 手绘爱心

- 类型：`illustration-sticker / symbol / heart-outline`。
- 白色空心手绘线稿。
- 参考锚点 `(61%W, 43%H)`，位于主体上方偏右。
- 宽约 `4.5%W 至 6%W`。
- 可选出现 0 或 1 次。
- 爱心必须小于风线贴纸，不承担主要视觉重量。

### bakery 装饰文字

- 类型：`text-sticker / decorative-word / serif`。
- 文字内容固定或从同类短词库随机选择，不是用户文本框。
- 参考位置在主体右上侧，锚点 `(79%W, 53%H)`。
- 默认顺时针旋转约 `24°`。
- 字体为轻盈高对比衬线体，颜色为白色。
- 字号约为画布高度的 `2.4% 至 3.0%`。

### foodie mood 装饰文字

- 类型：`text-sticker / decorative-phrase / serif`。
- 文字内容固定或从同类短语库随机选择，不是用户文本框。
- 位于主体左下侧，参考锚点 `(29%W, 77%H)`。
- 默认逆时针旋转约 `-33°`。
- 字体、颜色与 `bakery` 保持一致。
- 两个装饰文字形成左右对角关系，不应同时水平摆放。

## 自动复刻流程

1. 裁切或扩展输入图为 3:4，并保留原始场景背景。
2. 载入固定形状的局部暗层遮罩，放在背景上方和主体下方。
3. 获取餐品主体：多物件主体组缩放至画布宽度约 72%；单圆盘缩放至约 45%，外接框中心放在 `(50%W, 67%H)`。
4. 在局部暗层遮罩上方创建与圆盘同心、单侧留缝约 `2.7%W` 的白色圆形描边，再放置主体；颜色、粗细和留缝接受参数覆盖。
5. 在主体上方偏左放置风线涂鸦，补偿主体偏下造成的上方空缺。
6. 可选放置一枚小爱心。
7. 从装饰文字贴纸库选取两个衬线文字贴纸，沿主体右上与左下形成对角分布。
8. 检查暗层遮罩是否仍能透出背景、主体是否明显偏下、上方插画是否达到视觉平衡。

## 验收标准

- 主体保持水平近中、垂直偏下，不能误做成上一招的完全居中构图。
- 原始背景、局部暗层遮罩和主体三个层次清楚可辨。
- 暗层遮罩没有铺满全画面，也没有压暗主体。
- 描边是位于盘沿外侧的独立正圆，可修改颜色、粗细和留缝，不得遮住盘面。
- 上方风线贴纸必须出现，并承担平衡上方空间的功能。
- 爱心最多一个；装饰文字使用衬线体并沿对角方向摆放。
- 不调用 AI 临时生成遮罩、描边或贴纸。

## 用户需要提供

### 必需

- 一张透明底或可分离的单餐品主体图。
- 背景由模板背景素材库提供；运行时从用户提供的背景图中选择与主体色调相近的一张，而不是临时由 AI 生成。

### 可选

- 指定描边颜色和粗细。
- 指定装饰文字；未指定时从 `bakery`、`foodie mood` 及后续同类词库随机选择。
- 若要求与参考图逐像素一致，可提供高清透明底风线和爱心素材；当前资产为按参考风格重建的矢量母版。
