# 模板文本排版坐标规范

## 用途与读取方式

这是所有已审核模板的**文本几何唯一说明**。数值从 Figma 已验证版逐层读取，不从参考图估算。

- 运行时唯一机器可读来源：[template-text-layouts.v1.json](../app-contract/template-text-layouts.v1.json)。每个模板的 `manifest.json` 通过 `text_layout_ref` 引用自己的稳定模板 ID。
- `frame` 格式为 `[x, y, width, height]`，原点在左上，单位为 Figma 验证工作区像素；字体、字号、对齐、行高、旋转都必须保留。
- 模板编译器按 `reference_canvas_px` 把这些数据缩放并转换为 `canvas-scene.v1` 的 `0–1` 坐标。Swift 不得维护第二份坐标。
- `1_模板1` 与 `1_模板2` 的 Figma 外层测试容器为 `402×874`，但实际工作构图是 `402×713`；只使用 `402×713` 作为坐标基准。其余模板均为 `402×536`。
- `fixed_index`、`fixed_word`、装饰文案仍应生成独立 `text` 层，便于编辑；星星、箭头、颜文字等固定贴纸的内部文字随其 SVG/贴纸资产处理，不另起一套运行时文本坐标。

## 统一字体与运行时边界规范

- 文本层的 `font.family` 只能是 `黑体-简`、`American Typewriter`、`BM Yeonsung`、`Georgia` 或 `Coming Soon`。
- `黑体-简` 的当前模板字重使用 Regular；需要保留原粗体视觉的层在机器契约中标记 `font.is_bold: true`，由 App 合成加粗。`American Typewriter Bold` 使用原生 Bold；原 Medium 已统一为目标字体的 Regular。
- 每个文本层同时定义 `color`、`z_index`、`max_lines` 与 `overflow`。它们是运行时约束：只限制动态内容渲染，不回写或改变已经验收的 Figma 文本框、坐标、字号、字重、对齐、行高或旋转。
